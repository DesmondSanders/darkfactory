# MVP Roadmap (12–16 Weeks)

## Phase 1 (Weeks 1–4): Foundations
- Control plane skeleton + SSO/RBAC.
- Model abstraction layer.
- Audit event pipeline (immutable append-only).
- Jira/ADO + GitHub/GitLab basic adapters.

## Phase 2 (Weeks 5–8): Core Agent Workflows
- Initiative decomposition + backlog sync.
- Policy engine v1 (Suggest-only + HIL).
- Approval workflows (UI + Slack/Teams).
- Branch/PR automation with gating.

## Phase 3 (Weeks 9–12): Quality + Release
- Test plan/test generation + CI publication.
- Release readiness gate evaluator.
- Dashboard v1 (status, risk, activity).

## Phase 4 (Weeks 13–16): Pilot Hardening
- HOL mode with exception policies.
- ServiceNow + observability integrations.
- KPI instrumentation and pilot reporting.
- Security/compliance hardening and runbooks.

## Pilot Rollout
- Single product team.
- Weekly governance review.
- Expand only after KPI and reliability thresholds met.
