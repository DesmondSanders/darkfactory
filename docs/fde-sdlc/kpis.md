# 90-Day Pilot KPI Framework

## Primary KPIs
1. Lead Time for Changes
   - Target: >=20% reduction vs baseline.
2. Deployment Frequency
   - Target: >=15% increase vs baseline.
3. Incident Safety
   - Target: no increase in Sev1/Sev2 incidents.

## Supporting Metrics
- Approval turnaround time.
- Agent action success rate.
- Rework/rollback rate.
- Gate failure reasons distribution.
- Autonomy mode adoption by workflow.

## Measurement Method
- Baseline window: prior 30–60 days.
- Pilot window: 90 days.
- Normalize by team size and release volume.
- Weekly trend + monthly executive summary.
